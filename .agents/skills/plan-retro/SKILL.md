# plan-retro

Locate the plans checkout from an explicit task path or the PLANS_DIR environment variable. If neither is available, use the current checkout only if it contains plan-spec.md and working-agreement.md; otherwise ask for its location. Read those two files in the plans checkout before acting. Resolve templates, context, plans, and handoffs against that checkout, never against the skill installation directory. Work on code in the separately identified repository checkouts.

Read relevant done and discarded plans, handoffs, and user-provided corrections. Use accessible transcripts only when relevant; do not assume access. Identify recurring friction, missing context, inaccurate completion claims, or unnecessary process. Propose small edits to shared rules, context, or skills with evidence and expected benefit. Keep preferences tentative when evidence is weak. Apply changes only when the user has authorized improvement edits; otherwise present the proposed changes. Do not create universal restrictions from isolated incidents.
