## Reporting
Write your handoff after meaningful progress, decisions, blockers and before stopping. Distinguish implemented from verified. Publish authorized code commits/PRs, then handoff evidence using the agreed route. In a shared checkout the coordinator serializes Git publication. Record unsynced outputs explicitly.

Notify the verified coordinator at every stop: completed, blocked on a permission or decision, or waiting on CI, review or another agent. Save the handoff first. Waiting is reported, never a reason to defer the notification; a later result is a new notification. Include plan/assignment ID, handoff path and published ref. Do not assume an old machine binding is current. Save failed-delivery evidence; plan-sync/fallback can discover the durable update. The coordinator owns shared lifecycle state. This assignment does not expand publication, merge or deployment authority.
