# Starting a coordinator

Use coordinator-start with a scope and PLANS_DIR. Start with the scope profile, Git status and targeted plan summaries. Recover active ownership, blockers and unreviewed updates without loading completed work or every draft in full. Brief the user and stop unless refinement or execution was also requested.

Do not automatically inspect product source or machine capabilities during startup. Read working-agreement.md and plan-spec.md before changing state. Load sync.md for synchronization/publication/ownership transfer, and updates.md for workspace setup, notifications or optional fallback. A profile or startup brief does not dispatch workers or install a background loop.

Lifecycle directories and plan Current state sections are the status index; do not maintain a competing dashboard. Herdr workspace/session bindings are local and must be verified when used.
